# Aribot extension for Gemini CLI

Connects Gemini CLI to [Aribot](https://aribot.ayurak.com) through its remote MCP server
(`https://mcp.aribot.ayurak.com/mcp`, OAuth sign-in with your Aribot account).

```
gemini extensions install https://github.com/Aristiun-B-V/aribot-gemini-extension
```

Then run `/mcp auth aribot` inside Gemini CLI to sign in.
